# SkillOutcome

## SIH26135

Longitudinal skilling-outcome and impact measurement platform.

## Problem

Existing skill development systems track training completion but fail to measure employment outcomes, retention, wage growth and skill gaps.

## Solution

A platform connecting:

Training
↓
Certification
↓
Employment
↓
Retention
↓
Skill Intelligence
↓
Policy Decisions


## Tech Stack

Frontend:
React + TypeScript

Backend:
FastAPI + PostgreSQL

AI:
Python + Machine Learning
